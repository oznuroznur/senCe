# Frontend Agent Instructions - Sence Backend API

Bu dosya, Sence Backend API'sini kullanan frontend gelistirme ajanlarina yonelik kaynak belgeleri ve kilavuzlar icerir.

## Baslangic

### API Base URL

- Development: http://localhost:3000/api
- Production: ortam degiskeni ile ayarlanir

### Swagger/OpenAPI

- Interactive Docs: http://localhost:3000/api/docs
- OpenAPI JSON: http://localhost:3000/api/docs/json
- OpenAPI YAML: http://localhost:3000/api/docs/yaml

## Authentication

Clerk JWT ile Bearer token kullanilir.

```ts
import { useAuth } from "@clerk/nextjs"

const { getToken } = useAuth()
const token = await getToken()

await fetch(`${API_BASE}/endpoint`, {
  headers: {
    Authorization: `Bearer ${token}`,
    "Content-Type": "application/json",
  },
})
```
